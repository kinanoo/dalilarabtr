## Hard constraints (learned the hard way — do not relearn them)

- **Supabase env vars are not available locally.** A local `next start` renders every page with no
  database, so behaviour verification must happen on **production after deploy**. Still run
  `npm run build` and `npx tsc --noEmit` before every push.
- On Workers, `dynamic='force-static'` + `dynamicParams=false` **404s live**. Use `revalidate=<n>` +
  `dynamicParams=true`.
- In-render `redirect()` returns **200** on this deployment. Redirects declared in `next.config.ts`
  correctly return **308**.
- You cannot write to the database. Content changes ship as an **idempotent `.sql` file under `sql/`**
  for the owner to run. Article status is `'approved'`, never `'published'`.
- Article pages map the DB row into a **new object** in `getArticle()` — adding a column to the
  `select` is not enough, the mapper must carry it too.
