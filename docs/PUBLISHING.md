# كيف تنشر محتوى على دليل العرب

دليل مستقلّ لأي مساهم — مبرمج أو وكيل ذكاء اصطناعي — يريد نشر خبر أو مقال.
لا يفترض معرفة سابقة بالمشروع.

---

## الطريقتان، ومتى تستخدم كلاً منهما

| | لوحة التحكم | ملف SQL |
|---|---|---|
| **الرابط** | `/admin/updates` و`/admin/articles` | ملف في `sql/` يُدمج في `main` |
| **تناسب** | خبر عاجل بسيط، تعديل سريع | خبر + مقال معاً، تحديث مقالات قائمة، أي شيء يحتاج مراجعة |
| **المراجعة** | لا أثر في git | كل شيء في تاريخ git ومرّ بـPR |
| **من يستطيع** | صاحب الموقع (بحساب admin) | أي مساهم عبر PR |

**القاعدة:** لوحة التحكم للسرعة، وSQL لكل ما يحتاج دقّة أو تتبّعاً. الوكيل
الآلي يستخدم SQL دائماً — لأنه لا يملك جلسة admin، ولأن عمله يجب أن يكون
قابلاً للمراجعة قبل أن يصل إلى قارئ.

---

## طريقة SQL — الخطوات

### 1. أنشئ ملفاً في `sql/` باسم مؤرَّخ

```
sql/YYYY-MM-DD_وصف-مختصر-بالإنجليزية.sql
```

التاريخ ليس تجميلاً: **الترتيب الأبجدي هو ترتيب التنفيذ**، فملف يعتمد على آخر
يجب أن يلي تاريخه.

### 2. اتبع البنية المتوقَّعة

```sql
-- ============================================================================
-- عنوان الملف والتاريخ
--
-- المصادر (مع تاريخ التحقّق):
--   * <رابط المصدر الأوّلي>
--
-- ملاحظات على ما صُحِّح أو استُثني ولماذا.
-- ============================================================================

-- الخبر: WHERE NOT EXISTS يمنع التكرار
INSERT INTO public.updates (type, title, content, summary, category,
                            source_name, source_url, link, date, active, pinned)
SELECT 'news', $t$العنوان$t$, $c$<p>المتن</p>$c$, $s$الخلاصة$s$,
       'official', $n$اسم المصدر$n$, 'https://...', '/article/<slug>',
       CURRENT_DATE, true, false
WHERE NOT EXISTS (
  SELECT 1 FROM public.updates WHERE title = $t$العنوان$t$
);

-- تحقّق: يفشل صراحةً بدل أن ينجح صامتاً
DO $check$
DECLARE n integer;
BEGIN
  SELECT COUNT(*) INTO n FROM public.updates
  WHERE title = $t$العنوان$t$ AND active = true;
  IF n <> 1 THEN
    RAISE EXCEPTION 'FAILED: expected 1 row, found %', n;
  END IF;
  RAISE NOTICE 'OK';
END
$check$;
```

استخدم `$t$ … $t$` وأخواتها بدل علامات التنصيص — المحتوى عربي وفيه علامات
اقتباس وHTML، والهروب اليدوي مصدر أخطاء.

### 3. افتح PR وادمجه

عند الدمج في `main` يطبّق `.github/workflows/apply-sql.yml` الملف تلقائياً
ويسجّله في `public.sql_migrations` فلا يتكرّر. **لا خطوة يدوية.**

## الحقول التي تقرّر أين يظهر المحتوى

### `public.updates` — الأخبار

| الحقل | ملاحظات |
|---|---|
| `type` | `news` أو `alert` أو `feature` |
| `category` | `official` / `residence` / `work` / `education` / `health` / `security` / `general` — تُستخدم كفلاتر في `/updates` |
| `summary` | يظهر في القائمة بدل اقتصاص المتن. اكتبه دائماً |
| `source_name` / `source_url` | المصدر الأوّلي، لا الوسيط الذي نقله |
| `link` | `/article/<slug>` لمقال **موجود فعلاً**، أو `NULL` |
| `date` | `CURRENT_DATE` |
| `created_at` | افتراضياً `NOW()` ويُشعِر المشتركين. عند إدراج عدة أخبار دفعةً، اجعل الثانوية `NOW() - INTERVAL '3 hours'` كي لا تنزل إشعارات متزامنة |

### `public.articles` — المقالات

`category` هو ما يقرّر ظهور المقال في الصفحات المجمِّعة:

| الصفحة | الشرط |
|---|---|
| `/e-devlet-services` | `category = 'خدمات e-Devlet'` و`status = 'approved'`. تستخدم `source` لزر «زيارة الموقع» و`slug` لزر «اقرأ الشرح» — `source` فارغ = كرت ناقص |
| `/health`, `/work`, `/education`, `/residence`, `/housing` | تصنيفات عربية — **افتح ملف الصفحة وتأكّد** من القيمة التي تستعلم بها بدل التخمين |

الوسم `دليل` في `tags` يُدرج المقال ضمن الأدلة العملية، ويتطلّب 3 خطوات على
الأقل في `steps`.

## أخطاء وقعنا فيها فعلاً — لا تكرّرها

### `scripts/_article-corpus.json` لقطة قديمة لا مصدر حقيقة

وجود slug فيه **لا يعني وجوده في القاعدة**. حدث أن ملفاً اشترط تحديث مقال
مُدرَج فيه لكنه مفقود، فأسقط بلوك التحقّق العملية كلَّها **وضاع الخبر السليم
معها**.

**القاعدة: لا تجعل تحديث مقال شرطاً لنجاح خبر.**

```sql
-- استهدف قائمة مرشّحين لا slug واحداً
WHERE slug IN ('candidate-1', 'candidate-2', 'candidate-3')

-- واحسم الرابط إلى slug موجود فعلاً، أو اتركه NULL
-- (رابط مكسور أسوأ من غياب رابط)

-- وفي بلوك التحقّق: EXCEPTION للخبر وحده، NOTICE للمقال
```

### الملف المطبَّق لا يُعدَّل

التعديل لا يُعاد تطبيقه — يُنتج تحذير بصمة فقط. **أي تصحيح يحتاج ملفاً جديداً
بتاريخ جديد.**

### المعاملة الواحدة

كل ملف يُطبَّق داخل معاملة: إمّا كلّه أو لا شيء منه. إن احتاج تنفيذاً خارجها
(`VACUUM`، `CREATE INDEX CONCURRENTLY`) ضع في **السطر الأول** بالضبط:

```sql
-- @no-transaction
```

## معايير المحتوى

**المصدر الأوّلي إلزامي.** بيان رسمي، جريدة رسمية، موقع وزارة — لا قناة تلغرام
ولا صفحة تواصل ولا موقع ناقل.

**صحّح ما يتداوَل صراحةً في المتن.** إن ناقض المصدر الرسمي الشائعَ فقُل ذلك
بوضوح. أمثلة حقيقية من أرشيف الموقع:

- تُداول أن العائدين إلى سوريا يتلقّون «275 يورو للفرد» — المفوضية تنصّ على
  أنها **لا تقدّم أي مساعدة نقدية في تركيا**، والمنحة الموثّقة 600 دولار
  للأسرة تُصرف **داخل سوريا** ومشروطة بالتمويل.
- تُداول أن جنسية 687 شخصاً «أُلغيت» — النصّ الرسمي: `iptal edilecek`، أي أن
  الإجراءات **بُوشرت** ولم يصدر إلغاء نافذ.
- تُداول أن سقف خطوط الهاتف للأجانب 3 — صحيح **لحامل الرقم الأجنبي فقط**، أمّا
  من يتعامل بجواز سفره فسقفه **خطّ واحد**.

**اعرف الجمهور.** غالبيته سوريون تحت الحماية المؤقتة. تعميم قاعدة لا تنطبق على
حامل الكملك ليس نقص دقّة — بل ضرر مباشر. تحقّق دائماً: هل هذا الحكم يشمل
الحماية المؤقتة أم الإقامات فقط؟

**الخبر يُعلن، والمقال يشرح.** إن كان الخبر عن خدمة أو إجراء يفعله القارئ
بنفسه، فهو يحتاج مقالاً مرافقاً بالخطوات — أنشئهما في الملف نفسه.

