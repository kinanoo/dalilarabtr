# Service directory research

This folder is the reviewable source ledger for service-provider imports.

## Rules

- Google Maps may be used for discovery, but it is not copied as a database.
- A provider is not published from a map result alone.
- The directory accepts providers operating in Turkey who present their name,
  business, or services in Arabic.
- Arabic presentation is enough for inclusion; provider nationality or ethnic
  identity is not investigated or required.
- Core facts must be confirmed on a provider-owned website, an official
  registry, or a provider submission.
- Do not copy Google photos, reviews, ratings, or descriptions.
- Do not claim that a provider speaks Arabic unless its own source says so.
- Images stay empty unless the provider owns the image and permits its use.
- Phone-based duplicate checks run again immediately before publication.
- `source_checked` means contact details were checked; it is not a guarantee,
  recommendation, licence, or quality certification.
- Correction and removal requests remain available to providers and visitors.

Each batch is staged in the admin review queue before any row reaches the
public directory.
